上线前需要配置

  1. 在微信公众平台注册小程序并获取 AppID/AppSecret。
  2. 把后端部署到 HTTPS 域名，并加入小程序服务器域名白名单。
  3. 修改小程序 config.js 中的 API 地址。
  4. 生成正式版二维码：npm run generate:qr。

未配置微信凭据时，系统仍可在开发工具中运行和测试，但无法生成真实微信小程序码。
